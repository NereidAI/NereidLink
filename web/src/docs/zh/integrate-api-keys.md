# 使用用户 API 密钥接入

用户 API 密钥允许外部集成以现有人类用户身份调用 NereidLink REST API，而无需保存该用户的密码。

## 请求头

通过 `X-Api-Key` 请求头发送密钥：

```http
GET /v1/tenants/{tenant}/devices
X-Api-Key: nlk_<52 个小写、无填充 base32 字符>
```

不要将密钥放在 URL 查询参数中。网关会在每次请求时检查密钥；系统不提供令牌交换，也不缓存正向凭据验证结果。

## 权限

- 未设置显式范围的密钥会继承所有者当前的角色和数据范围。
- 设置显式范围后，密钥只能使用这些权限点；每个权限点都必须在创建时和每次请求时仍由所有者持有。
- 禁用所有者或租户后，密钥会立即失效。
- 吊销密钥后，它会立即不可用。

## 生命周期

完整密钥仅在创建或轮换后显示一次。此后控制台和 API 只展示非密钥前缀。轮换会生成新的凭据和前缀；已吊销或已过期的密钥不能轮换。软吊销会保留数据库行和审计历史；硬删除会移除该行，而审计事件仍保留密钥 ID 和前缀。

管理密钥必须使用交互式登录会话。API 密钥不能创建、轮换、吊销或删除密钥，以避免受限凭据扩大自身访问范围。租户管理员可在**用户与角色 → API 密钥**页签中查看、吊销和删除本租户任意用户的密钥；用户本人则在**账户安全**页创建和轮换自己的密钥。
