# 配置下发

**配置下发**用于把租户设备配置[库](help:page/profiles)中的某个配置，推送给未上报它的网关，且无需重写源文本。它实现的是共享库分发路径（ADR-0038)：网关 A 上报了配置 `A1`，平台把 `A1` 作为租户资产保存，操作员把同一个 `A1` 推给从未上报过它的网关 B。平台只引用库条目及其版本，文档由云端按各网关在 hello 中声明的格式渲染，因此该机制不绑定 EdgeX。

界面上有两个互补的入口。

## 从配置发起分发

打开**设备配置**，进入某个配置详情，滚动到**分发到网关**卡片。

1. 点击**分发到网关**。
2. 选择一个在用网关。已存在显式分发目标的网关不再列出；仅通过连接器持有该配置的网关仍可被设为显式目标。当前固件未协商该能力的网关，在选择项中会标注**固件不支持**。
3. 确认。网关在线时立即下发期望帧；离线时保持待下发，并在每次重连后幂等重发完整期望集合。

卡片会列出该配置触达的每一个网关：

- **已分发**——你创建的显式分发边，该行提供**撤回**操作。
- **连接器引用**——网关因某个连接器实例引用而持有该配置。此行为只读：它不是显式目标，因此这里没有可撤回的对象。

每行显示状态以及**已生效 / 已下发 / 期望**三段版本号。

## 在网关上分发与查看

打开网关详情页，使用**配置下发**页签。它列出该网关持有的每个库配置、相同的状态与三段版本号，并且可直接管理：

1. 点击**分发配置**，选择一个尚未分发给本网关的库配置。仅通过连接器持有的配置不会作为重复项出现，但仍可通过分发把它提升为显式目标。
2. 确认。行为与在配置详情页分发完全一致。
3. 标注**已分发**的行提供**撤回**；标注**连接器引用**的行为只读，因为没有可移除的显式边。

当存在进行中的行时会短暂轮询，其余情况提供**刷新**按钮；状态达到**已生效**后无需持续刷新。无论从哪个入口分发或撤回，底层都是同一条分发边，因此两个视图始终一致。

## 状态

- **待下发**——目标已记录，但尚未写入网关。
- **下发中**——期望帧已在通道上推送。
- **已生效**——网关已上报该配置达到期望版本。
- **失败**——网关拒绝了内容；悬停标签可查看原因。
- **已拒绝**——网关拒绝应用该配置；悬停可查看原因。
- **撤回中 / 已撤回**——撤回流程。

配置长时间停留在待下发/下发中会产生警告告警；持续失败的下发会按与连接器、密钥下发一致的方式从重要升级到紧急。

## 撤回

**撤回**会移除显式分发边。只有当显式边已删除**且**没有任何连接器实例仍引用该配置时，平台才会通知网关删除副本；否则配置会保留，因为连接器仍需要它。撤回绝不会删除租户库中的原始配置。

## 固件能力

只有当网关在最近一次 hello 中协商了 `profiles` 能力、并声明了一个或多个支持的 `profile_formats`（内置格式为厂商中立的 `nereid-neutral/1` 与 EdgeX 适配 `edgex-device-profile/3`）时，才会收到配置帧。缺少该能力时，网关页签会提示**网关固件不支持配置下发**：此时可以先记录目标，固件升级后自动下发，升级前绝不发送。在边缘端下行能力部署完成之前，由于尚无边缘回报**已生效**，各行通常停留在**下发中**。
