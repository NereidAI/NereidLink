# NereidLink 产品能力总览

NereidLink 是面向企业私有化部署的 IoT 管道平台，提供多协议设备接入、
统一消息管道、规则引擎、告警通知与实时可视化能力。新一代版本的
服务端与边缘端经过完整重写，围绕 **实时、简单、安全、开放** 四个
目标设计，线协议与旧版本不兼容。

本文档按平台领域分类描述产品能力，并随产品版本持续补充完善。

---

## 1. 实时通信架构

- **全量数据 WebSocket 推送**：遥测、在线状态、属性、设备影子、
  设备域事件、告警、命令进度、连接器状态、密钥绑定、OTA 进度等
  所有数据变化均经 WebSocket 毫秒级推送，禁止轮询。
- **单连接多路订阅**：一条 WebSocket 连接承载多个订阅，服务端
  纯推送；支持断线重连与会话恢复。
- **推送隔离**：帧数据严格按租户隔离，并与 RBAC 数据范围联动——
  受限用户的通配订阅在服务端物化为其可见设备集，帧不跨租户、
  不越权。
- **慢客户端保护**：每条连接配备有界非阻塞发送队列与唯一写协程，
  半开连接或消费过慢的客户端被丢弃，不影响其他在线用户。
- REST 仅承担一次性快照、查询与写入，实时性全部由 WebSocket 保证。

## 2. 设备接入与管理

- **四种设备凭据**：
  - TOKEN：服务端生成随机密钥，恒定时间比较；
  - PASSWORD：argon2id 哈希存储，兼容旧明文校验；
  - JWT：支持多种签名算法与远程 JWKS 拉取，密钥标识与算法双重
    匹配，防算法混淆，异常时失败即关闭；
  - X.509：双向 TLS，叶子证书指纹匹配并检查证书吊销列表（CRL）。
- **凭据全生命周期**：生效/失效时间窗、启用停用、就地轮换、
  重叠窗口轮换（先注册新凭据再停用旧凭据）、到期扫描预警。
- **设备生命周期**：预注册（UNCLAIMED）与单次限时认领令牌；
  客户/分组间移交（设备标识与时序数据连续）；非破坏性报废
  （凭据禁用不删除、保留召回窗口）、窗口期内恢复、超期归档终态。
- **简单的绑定关系**：网关与子设备为纯粹的包含关系，仅一个归属
  字段；设备列表自动分类网关 / 子设备 / 独立设备，支持按所属网关
  过滤，详情双向展示归属。
- **批量能力**：CSV/XLSX 批量导入（含模板下载、校验预览）、
  批量报废；Profile 同样支持批量导入。
- **设备别名与备注**：可设置无语义的展示别名与自由备注，列表
  支持按名称或别名检索。
- 仅处于正常状态的设备可认证、可接收命令、可持久化遥测。

## 3. 命令与远程控制

- **同步等结果**：简化的命令帧支持请求-响应模式直接等待执行结果；
  离线设备立即返回"未连接"，不排队、不假装成功。
- **两个正交维度**：交互方式（单向 / 请求-响应）与数据方向
  （读 / 写），独立读写掩码，越权方向被拒绝。
- **命令目录白名单**：命令必须先在目录中声明（命令具有副作用，
  目录即安全边界），支持启用开关、超时、读写掩码；目录条目可由
  Profile 点位自动物化。
- **批量命令**：按设备组子树或显式列表派发（上限千级目标），
  逐项认领、部分失败不回滚，聚合进度实时推送。
- **网关中继命令**：命令直达子设备所属网关，严格校验子设备挂载在
  该网关连接上；网关返回结果走同一套关联、超时与迟到纠正机制。
- **网关操作目录**：对整个网关的即时操作（重启、配置等）以数据化
  目录管理，支持参数/结果 Schema、风险分级（只读/普通/危险）、
  按租户禁用。
- **按需探测**：对网关下设备发起即时探测任务，按网关聚合成帧，
  实时回收逐设备结果。
- **结果最终一致**：迟到的设备响应可把已超时记录纠正为成功。

## 4. 遥测与数据管道

- **统一上行信封**：MQTT / HTTP / CoAP 三种入口共用同一套 SDK 与
  信封，传输无关的解析逻辑只存在一处，各入口行为完全一致。
- **类型化点位**：数值 / 布尔 / 字符串三类，数值按描述符执行
  变换，布尔与字符串原样承载；单位只来自用户定义的描述符，
  平台从不猜测单位。
- **内核协议无关**：平台不解析任何具体行业协议、不内置业务逻辑，
  边缘网关与直连设备均通过通用 SDK/线契约接入。
- **接入限流**：按设备令牌桶在消息骨干前限流，超限帧被丢弃或
  返回限流错误，不进入流处理。
- **总线压缩**：内部消息支持可选压缩（LZ4 类 / zstd），带协议
  魔数字头，支持热切换并兼容已在途消息。
- **数据外发旁路**：向第三方系统转发为异步旁路，每个目的地独立
  数据流与背压隔离，格式与通道可插拔。
- **死信队列（DLQ）与存储钩子**：处理失败的消息可在 DLQ 检视，
  持久化环节支持用户自定义存储钩子。

## 5. 数据存储与设备状态

- **统一数据底座**：PostgreSQL + TimescaleDB，实体数据与时序数据
  合一；对象存储（S3 兼容）承载固件包、导入导出与冷数据。
- **分层存储**：Hot / Warm / Cold 三层，仅 Cold 层可删且限运维
  操作；原始遥测、连续聚合与压缩策略由平台统一维护。
- **保留策略**：按租户、按数据域（遥测/事件/告警/审计）配置保留
  天数，支持法律冻结（冻结期内暂停自动删除）；删除由后台执行器
  统一完成，缩短保留期不触发即时删除。
- **设备影子**：期望态/上报态合并、差异集（delta）、同步状态
  漂移检测、ETag 乐观并发控制；期望态立即下发并在设备上线时重推。
- **三作用域属性**：客户端 / 服务端 / 共享三个作用域，设备可上报
  客户端属性，平台可下行服务端与共享属性。
- **设备域事件**：带类型、严重度与负载的追加式事件账本与实时
  推送，独立于遥测管线；平台只存储与路由，不按事件内容做业务分支。

## 6. 规则引擎与自动化

- **版本化规则链**：规则以链为单位版本管理，平台为每租户预置
  根规则链。
- **可视化编辑器**：基于节点编排的规则链编辑器，含节点面板与
  配置面板。
- **三档脚本能力**：内嵌表达式 → 嵌入式 JavaScript（goja）→
  外挂任意语言运行器，按复杂度逐级选择。
- 平台自身不携带业务逻辑，所有数据变换与联动均由租户定义的规则
  表达。

## 7. 告警与通知

- **告警生命周期**：触发、确认、清除完整状态机，支持指派处理人
  与评论协作。
- **升级链**：按告警起点编排有序延迟步骤与目标角色，确认或清除
  即停止；支持固定节奏重复提醒，跨重启不重发。
- **多通道投递**：站内信、Webhook、SMTP 邮件，通道可独立部署
  与扩展。
- **链路告警**：网关非计划断链自动开告警、恢复即清除；主动关机
  不告警；链路抖动自动识别。
- **每日断链摘要**：按网关聚合断链次数与总时长，每租户每天一封。
- **平台级故障兜底（dead-man）**：与租户通知体系完全隔离的独立
  通道，数据库与消息总线等依赖连续探测失败时直发平台故障报告。

## 8. 边缘管理

- **握手协商与会话恢复**：边缘上线即协商协议版本与特性集，版本
  不重叠或必需特性缺失即拒绝；重连可在有效期内复用原会话，
  下行配置全量幂等重放。
- **连接器全生命周期**：连接器期望态由平台统一下发，边缘上报
  实际状态（创建中/已生效/失败/降级），形成完整状态机。
- **两级配置**：Profile 连接器模板 + 实例级覆盖，派发时深合并
  生成有效配置；插件版本由平台侧自动选择。
- **Schema 校验与漂移对账**：边缘上报连接器配置 Schema，写入前
  即校验；周期性清单对账识别缺失、过期、漂移与多余实例，可选
  严格模式自动纠偏；实例级健康探测可由边缘自主断言上下线。
- **自动发现与注册**：边缘上报本地候选设备，策略按网关、租户、
  部署三级继承，可设自动注册或人工审批。
- **配置清单对账**：边缘周期性上报在线子设备全量清单，平台事件
  驱动对账，漂移给出告警建议，租约过期精确一次级联下线；
  注册表永不被上报帧自动改写。
- **链路看门狗**：心跳保活、疑似/断链分级、抖动识别，处理逻辑
  独立于连接平面。

## 9. OTA 固件升级

- **双固件来源**：外部 URL（边缘自行下载并强制 sha256 校验）或
  平台托管（对象存储加鉴权路径，边缘无需对象存储凭证）。
- **阶段化状态与结构化结果码**：待下发、已发起、下载中、已校验、
  更新中、重启中、已确认等前向阶段；配套十余种结果码（空间不足、
  完整性校验失败、版本不符、下载无进展、重启超时等），失败原因
  精确可诊断。
- **三方时间线**：每设备追加式时间线，区分平台、设备、网关来源；
  高频下载进度只推送不存储。
- **两种成功判定**：设备上报成功即完成（默认），或重启回连后以
  版本号确认成功。
- **灰度发布**：按百分比或固定批量分批，观察通过后再推进下一批。
- **熔断与看门狗**：失败率或连续失败超阈值自动熔断；停滞与重启
  确认由看门狗定时回收。
- **过程控制**：支持暂停、恢复与分级取消（未开始的立即停止，
  已在更新的不打断，继续回收结果）。
- **目标选择**：显式设备列表或按 Profile/分组/客户的动态选择器
  （创建时快照）；已是目标版本的设备自动跳过。
- **断点续传**：直连设备采用拉模式，支持单字节 Range 续传；
  升级成功后固件版本号自动写回设备档案。
- **固件仓库**：流式上传、发行说明、按型号稳定版互斥标记与型号
  适配校验。

## 10. 安全与合规

- **内置 CA 与 mTLS**：控制台直接签发 ECDSA P-256 设备证书，证书
  验证池每次握手重建，CA 导入或禁用免重启生效；CA 私钥从不入库。
- **多因素认证**：用户 TOTP（RFC 6239）与一次性恢复码；登录失败
  锁定、算术验证码、会话列表管理与单会话即时吊销。
- **危险操作二次确认**：危险操作需带签名的 TOTP 短时质询，一次性
  消费；机器身份不得执行危险操作。
- **RBAC 权限模型**：内置角色与细粒度权限点；权限决定"能做什么"，
  数据范围（租户/客户/分组）决定"能触达哪些数据"，读写两侧均在
  存储层收口。
- **密钥保险库**：租户密钥以 AES-256-GCM 加密、库外文件主密钥
  保护；明文只在下行最后一里还原，不落规格表、不上内部总线、
  不进 REST 与审计；删除受引用保护，强删仅限真人加 TOTP。
- **审计哈希链**：追加式审计日志逐条以前序哈希串联，配合每日封存
  锚点，可在线验链、防篡改。
- **设备隔离应急**：凭据失陷、流量洪泛、固件异常等场景可立即将
  设备踢下线并拒绝认证，身份与时序数据完整保留。
- **高危操作双确认**：运维从本地管理端口下单，超级管理员在 Web 端
  跨通道审批（含内容哈希比对）后才执行。

## 11. 多租户与许可计量

- **租户开通自动化**：创建租户即自动开通消息流、默认 Profile 与
  根规则链；失败任务自动重试或转人工。
- **租户运营**：支持租户暂停（立即拒绝新连接与写入）与恢复。
- **OAuth2 服务账号**：客户端凭证模式的机器身份，密钥支持重叠
  轮换，令牌携带细粒度权限点，且不能自行创建服务账号。
- **许可证管理**：许可证为签名信封，支持部署级与租户级；过期或
  超配时进入只读降级，已连接设备可继续上报。
- **时钟回拨防护**：数据库、NATS KV 与本地文件多点见证，回拨
  超限触发只读。
- **计量统计**：按日统计设备数、活跃设备数、消息量、逻辑字节与
  分层存储事实，为计费与容量规划提供数据。

## 12. 可观测性与运维

- **指标与仪表盘**：Prometheus 指标加 Grafana 仪表盘，覆盖基础
  设施、REST、接入限流、总线编码、命令、通知与 WebSocket 连接数。
- **租户业务指标**：设备总数/在线/离线（不含报废墓碑）、活动告警、
  在途命令、活跃规则链、凭据数、固件包数与长任务数。
- **通知 SLO 指标**：按通道与严重度统计投递成功率与端到端时延，
  可查 p50 / p95 / p99。
- **资源核算 Top-N**：采样统计接入流量，字节数绝不外推；按租户、
  设备、IP、协议、节点、主题六维聚合，回答"谁在消耗接入容量"。
- **统一错误信封**：错误响应为错误码、消息与跟踪 ID，支持请求
  标识贯通服务端日志。
- **运维工具**：平台健康自检、显式数据库迁移、备份标记与备份
  脚本、控制台统计页。

## 13. 开发者生态与交付

- **设备端 SDK**：公开 Go SDK，覆盖全部设备与网关主题（凭据、
  遥测、属性、命令、影子、OTA、连接器、发现、探测），不含后台
  循环与策略逻辑，附示例与集成测试。
- **适配器 SDK**：零内部依赖的公共适配器框架，内置 MQTT/HTTP
  入口直接复用。
- **设备模拟器**：MQTT、HTTP、CoAP 三种模拟器，支持自定义数量、
  负载与模板。
- **厂商中立 Profile 库**：第三方边缘上报即自动入库，协议族与点
  地址开放可编辑；同名漂移不自动覆盖，由人工或显式采纳解决。
- **设备服务目录**：Modbus、OPC-UA、ONVIF、BACnet、S7、LLRP、
  CoAP 等十余个官方设备服务以全局可管理数据维护，一处修改处处
  生效，自定义服务可增删。
- **在线文档**：线协议、接入指南与术语表全部在线文档化；应用内
  帮助中心提供覆盖每个页面的双语主题，交叉引用可机检。
- **交互式 API 文档**：OpenAPI 契约与 Swagger UI 编译进单二进制，
  气隙环境免 CDN 使用。
- **交付形态**：一套代码两种形态——all-in-one 单二进制或 Kubernetes
  微服务；最小有状态依赖仅 PostgreSQL + NATS（对象存储可选）。
- **国际化**：全界面与文档中英双语。
